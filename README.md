# 📊 Meu Primeiro Painel de Vendas

Projeto de análise de vendas desenvolvido no **Power BI**, com dados carregados via **SQL**, modelagem de relacionamentos no próprio banco e layout desenhado no **Figma**.

![Capa do painel](painel_vendas_capa_azul.png)

---

## 🎯 Objetivo

Construir um painel de vendas que permita acompanhar o faturamento, identificar as categorias e regiões de maior desempenho e entender a sazonalidade das vendas ao longo dos anos.

## 🔎 Principais Insights

- 💰 **Faturamento de 2025:** R$ 173 bi, com crescimento mais evidente a partir de **março de 2025** em relação a 2023.
- 🖥️ **Categoria líder:** Informática.
- 🗺️ **Região com mais vendas:** Sudeste.
- 📅 **Sazonalidade:** as vendas sobem todos os anos a partir de **outubro**, impulsionadas pelo 13º salário e pelas compras de fim de ano.

## 🛠️ Ferramentas Utilizadas

| Ferramenta | Uso |
|---|---|
| **SQL** | Carga dos dados e criação dos relacionamentos entre as tabelas |
| **Power BI** | Modelagem, medidas DAX e construção dos visuais |
| **Figma** | Design do fundo e identidade visual do painel |
| **Tabela Calendário** | Análises temporais (ano, mês, trimestre) |

## ▶️ Como Usar

1. Faça o download ou clone o repositório:
   ```bash
   git clone https://github.com/WallaceStenz/EducaDados.git
   ```
2. Execute o script `MeuprimeiroPaineldeVendas_PBIX.sql` no seu banco de dados.
3. Abra o arquivo `.pbix` no **Power BI Desktop**.
4. Atualize a conexão com a sua fonte de dados, se necessário.
